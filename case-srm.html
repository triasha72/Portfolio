M.S. thesis · scientific ML · applied ML · simulation reliability

Failure detection in time-series thrust data from simulated rocket motors.

This M.S. thesis develops reproducible Scientific ML and applied ML workflows for identifying simulation failures in time-series thrust data, with an emphasis on data quality, leakage prevention, and evaluation on unseen geometries.

At a glance

  • 15,120 simulated cases
  • 6,804 candidate simulator failures
  • Time-series preprocessing and feature engineering
  • Duplicate-geometry leakage removal
  • Unseen-geometry evaluation
  • Independent replication study

Why this is a reliability problem

A simulation campaign can fail silently: a result may be present in the dataset even when the underlying run did not represent a valid physical case. Before training a model, the project audits the campaign, identifies candidate failures, and separates genuine modeling signal from artifacts in the simulation data.

Method

I built Python and scikit-learn workflows for data audit, preprocessing, feature engineering, failure classification, and uncertainty-aware decision support. A central evaluation control was removing duplicate geometry leakage before model fitting, then testing on unseen geometries rather than randomly mixed observations.

What this project demonstrates

For me, the important outcome is not only the classifier score. It is the complete engineering chain: audit the data, identify the failure mechanism, prevent leakage, test on the right split, and verify that the result replicates. That is the same reliability mindset I bring to retrieval systems, surrogate models, and deployed ML services.
