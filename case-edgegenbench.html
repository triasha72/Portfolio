Benchmark design

The benchmark starts with a reproducible, 6,000-sample synthetic hybrid-electric and hydrogen aircraft-design dataset. It compares Ridge, Random Forest, HistGradientBoosting, and a multi-output PyTorch surrogate using training-only normalization and validation-based early stopping. The system is designed so that model selection is not separated from the downstream decision context.

Accuracy is not treated as the only output. The benchmark records uncertainty and feasibility behavior so that decisions can be deferred when the model is operating outside an acceptable confidence region.

Uncertainty and safety-aware decisions

EdgeGenBench adds conformal uncertainty and a false-safe-rate-aware feasibility classifier. An uncertainty gate defers risky designs to physics validation before constrained multi-objective optimization. That policy makes the trade-off explicit: a model should not accept a design simply because it predicts a favorable objective value.

Efficient inference with equivalence checks

The neural surrogate is exported to ONNX FP32 and dynamically quantized INT8. Prediction parity is validated before benchmarking model size, P50/P95 latency, and throughput. Conversion is treated as part of the engineering system: a fast model that does not reproduce its original predictions is not operationally equivalent.

Bounded Design Review Agent

The project includes a tested, bounded Design Review Agent with prediction, uncertainty, feasibility, optimization, physics-validation, and model-trade-off tools. The workflow produces evidence-backed recommendations, uses a physics fallback when needed, and is packaged as typed FastAPI and Docker APIs with integration tests.
