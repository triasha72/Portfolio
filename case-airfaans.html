Georgia Tech AE 6394 coursework · scientific ML · CFD surrogates · graph neural networks

Can a machine-learning model predict an aerodynamic flow field without hiding where it fails?

AIRFAANS is a scientific machine-learning study built on full AirfRANS CFD meshes. I compare a pointwise MLP, a MeshGraphNet-style model, and a point neural operator using the same data split, training budget, and engineering evaluation. The goal is simple: assess flow-field accuracy alongside pressure, lift, and drag, then preserve enough evidence to reproduce or challenge the result.

Status: Interpolation, six Reynolds-OOD treatments, and scarce-data replication are complete. Angle-of-attack OOD, uncertainty calibration, active learning, and operational readiness remain pending.

What the project does

Each AirfRANS case contains an irregular airfoil mesh, operating conditions, and CFD flow variables. AIRFAANS predicts velocity-x, velocity-y, pressure, and turbulent viscosity at every mesh node. It then checks the full predicted field and the lift and drag recovered from it. Cases are split by simulation, so nodes from the same CFD solution never appear in both training and test data.

Why compare three models?

The models use geometry differently. The pointwise MLP treats each node locally. MeshGraphNet passes information along the mesh. The point neural operator adds broader spatial context. Holding the data, normalization, seeds, and evaluation fixed makes the comparison about model behavior rather than changing experimental conditions.

Matched three-seed interpolation result

The preregistered interpolation comparison is complete for seeds 17, 29, and 41. Each of the nine treatments is evaluated on all 200 official full-mesh interpolation test cases.

MeshGraphNet: ux 0.3788 ± 0.0199 · uy 0.6703 ± 0.0720 · pressure 0.7693 ± 0.0557 · nu_t 0.6895 ± 0.0859 · CD MAE 0.2319 ± 0.0619 · CL MAE 0.3907 ± 0.1705.

Point neural operator: ux 0.4183 ± 0.0090 · uy 1.0314 ± 0.0133 · pressure 1.2125 ± 0.0268 · nu_t 0.8127 ± 0.0167 · CD MAE 0.3544 ± 0.0230 · CL MAE 0.2843 ± 0.0225.

MeshGraphNet has the lowest mean error for all four predicted fields and drag, while the point operator has the lowest mean lift error. No architecture is presented as universally best.

How the result is kept honest

The pipeline checks real VTK/PyVista ingestion, graph construction, checkpoint identity, and the pressure-plus-viscous force calculation against the official AirfRANS implementation. Each long evaluation saves one record per mesh and ties those records to a checkpoint SHA-256. That matters because a notebook disconnect should not turn a finished run into an unverifiable claim.

Verified scarce-data replication

A Pointwise MLP scarce-data replication is complete for seeds 17 and 23. Each checkpoint was evaluated on 200 saved full-mesh cases, with per-case records tied to its checkpoint SHA-256 and preserved Drive evidence bundles. The two-seed mean relative-L2 errors are velocity-x 0.3756, velocity-y 0.6686, pressure 0.8596, and turbulent viscosity 0.7625.

This is a descriptive two-seed result, not a broad uncertainty estimate. The complete evidence includes run logs, checkpoint hashes, per-case records, aggregate JSON, and diagnostic plots.

Remaining studies

Angle-of-attack extrapolation, ensemble uncertainty calibration, uncertainty-guided active learning, single-versus-two-GPU scaling, and a validated 3D-geometry extension remain pending. No unmeasured study is presented as a benchmark conclusion.

Scope

This is coursework research, not a production CFD solver or sponsored engineering engagement. AirfRANS data and model weights are not redistributed by this portfolio, and the reported conclusions apply only to the documented splits, budgets, and implementations.
