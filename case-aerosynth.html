Build the evaluation boundary before claiming the evaluator works.

AeroSynth-Eval is a research and engineering framework for evaluating synthetic aerospace inspection imagery against explicit, human-reviewable rubrics. The current repo is intentionally stronger on benchmark integrity than on model-quality claims.

At a glance

  • 48 frozen scenarios
  • 36 development / 12 protected test
  • 48 deterministic synthetic PNG assets
  • SHA-256 provenance and registry validation
  • 12-item balanced development annotation queue
  • Typed prompt/response and evaluation contracts
  • Optional local MLX-VLM single-asset development runner
  • Ruff + strict mypy + pytest + GitHub Actions
  • No aggregate VLM accuracy or human-agreement claim yet

View the repository →

Scenario and test design

The frozen matrix spans aircraft regions, anomaly types, materials, backgrounds, lighting conditions, and capture profiles. Exactly 12 scenarios are protected test cases so development decisions cannot silently consume the evaluation set.

Deterministic assets and provenance

Every scenario has a generated PNG with recorded generation specification, seed, renderer version, timestamp, and SHA-256 digest. Registry and manifest checks reject missing assets, mismatched metadata, and corpus drift before evaluation.

Human-review infrastructure

The repo contains a balanced development-only annotation queue and validated reviewer-response contracts. Synthetic rater fixtures test the agreement-analysis pipeline in CI but are explicitly excluded from any claim about human agreement.

MLX-VLM development path

The optional Apple-Silicon runner processes one development asset at a time only after validating corpus and image integrity. It binds the response to the exact asset, scenario, rubric, model, runtime, prompt, and image digest.

Current evidence boundary

The current version does not claim human-rater agreement, calibration, consensus labels, aggregate VLM accuracy, evaluator fine-tuning, or operational inspection capability. Those require genuine annotation and model runs beyond the existing contract and smoke-test layer.

Next useful milestone

The next high-value evidence is real independent human rating, at least two VLM baselines, human-versus-model agreement, error taxonomy, and confidence/abstention analysis on a protected evaluation protocol.
